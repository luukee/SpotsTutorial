SPOTS Signup and Login

Staff reference for how REDCap email_primary and spots_user_id affect Google and password sign-in on spotsymptoms.org. This page is unlisted — share the URL only with study staff.

Written for UTH study staff (for example Stacey and Brenda) answering onboarding questions.

How login matching works

After someone signs in, SPOTS gets their account email from UTHealth AWS Cognito (the auth system for spotsymptoms.org). That email is looked up in REDCap against email_primary or spots_user_id. There is no separate “Cognito email” field in REDCap — Cognito is only where the signed-in email comes from before we check REDCap.

Quick answers

Can a parent and child share the same email_primary and both report?
Yes. That is the normal design. After sign-in they get the Reporting as screen and pick Parent or Child.
Do we need a new REDCap email field for parent automated emails?
No. Keep using email_primary for assent, gift cards, and other parent emails.
When should a child’s own email go in spots_user_id?
Only if that child should sign in alone with their own email (including Google). Parent email stays on email_primary so automated parent emails still work.
Can that child use Sign in with Google?
Yes, if their Google account email matches the child’s spots_user_id. Only the child record matches, so they go straight in (no profile picker).
Does capitalization matter in spots_user_id?
Login matching is case-insensitive. Still enter emails in lowercase for consistency elsewhere in REDCap.
Does Google login use a special SPOTS username?
Google uses the Google account email matched in REDCap. Password signup still needs the User ID staff gave them. See participant wording below.

What to tell participants vs staff only

Tell participants

  • Sign in with Google using the same email that’s on their SPOTS record.
  • If they create an email/password account on spotsymptoms.org, they still need to enter the User ID staff gave them.

Staff only — do not tell participants

  • Don’t say “Google doesn’t need a SPOTS username.” That can confuse people into skipping User ID on password signup.
  • Field names like email_primary, spots_user_id, and Cognito stay internal.
